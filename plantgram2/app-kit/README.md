# 온실 예제 앱

식물 · 화분 · 그림자를 낱장 PNG 로 두고 Flutter 가 겹칩니다. 그림은
`../sprite-kit-2026-08-29/sheets/kit.png` 한 장에서 잘라 왔습니다.

```
flutter run -d chrome
```

## 어디까지 확인했나

- 한 장에서 무대 1 + 화분 3 + 식물 3 을 잘라 냄
- 화분이 **바닥에 닿는 자리**를 칸 한가운데에 놓음
- 화분의 흙 자리와 식물의 밑동을 맞춰 겹침
- 긴 화단에 같은 식물 두 그루 (심는 자리가 둘)
- 칸 좌표로 배치, 화면 높이 순으로 앞뒤 정렬
- 빈 칸을 눌러 심기, 식물을 눌러 고르기, 끌어서 옮기기
  (놓을 수 있으면 초록, 없으면 붉게)
- 화분 바꾸기 · 두 손가락으로 크기 · 저장 · 되돌리기

## 그림을 갈아 끼울 때

Dart 코드는 손대지 않습니다. 새 시트를 받아 자르기만 다시 돌립니다.

```
python3 ../sprite-kit-2026-08-29/tools/fit_grid.py  sheets/kit.png 4
python3 ../sprite-kit-2026-08-29/tools/slice_kit.py sheets/kit.png assets
```

`fit_grid.py` 는 돌아온 그림의 실제 바닥에 격자를 다시 맞춥니다.
생성기가 바닥을 옮기거나 키워도 기하만 맞추면 되므로 다시 받지 않습니다.

## 해 보고 물린 것

**바닥을 우리 격자대로 다시 깔기.** 받은 그림의 칠해진 타일은 일정한
격자가 아니라(간격이 제각각) 우리 격자와 맞지 않습니다. 그래서 바닥
픽셀만 덮어 다시 깔아 봤습니다 — 격자는 정확해졌지만 **벽·소품은 그림
것을 쓰고 바닥만 우리가 그리니 각이 서로 어긋나 뒤틀려 보였습니다.**
그림은 그림대로 씁니다. 격자는 자리를 고를 때만 표시합니다.

**화단이 두 칸을 쓰게 하기.** 시트의 화단은 칸 간격에 견주면 0.59칸입니다.
두 칸에 맞추려면 그림을 2.11배로 키워야 하는데, 화분들과 축척이 어긋나
화단만 크고 잘려 보였습니다. 화단은 지금 크기 그대로 한 칸에 둡니다 —
두 칸짜리는 **그 크기로 그려진 시트를 새로 받아야** 제대로 됩니다.

## 기준점을 어떻게 잡나

| | |
|---|---|
| 화분이 놓이는 점 | 그림에서 **바닥에 닿는 자리**를 찾습니다. 흙을 칸에 맞추면 흙은 화분 위쪽이라 키 큰 화단일수록 다리가 제 칸보다 앞으로 나갑니다 |
| 화분의 흙 | 그림에서 **색으로** 찾은 무게중심 |
| 식물의 밑동 | 그림에서 **맨 아랫부분 폭의 한가운데**. 안내선의 표시는 요청이지 측정값이 아닙니다 |
| 그림자 | 요청하지 않고 코드가 그립니다. 닿는 자리 폭에 맞춘 진한 반투명 타원 |
| 격자 | 바닥 네 꼭짓점에서 잰 두 방향 벡터. 마름모가 살짝 기울어도 정확합니다 |
| 심는 자리가 여럿 | 흙의 가로 범위를 자리 수만큼 **등분**. x 중앙값으로 가르면 등각 상자에서 좌우가 고르지 않게 갈립니다 |
| 자리별 식물 크기 | 자리 폭 ÷ 기준 흙 폭. 좁은 화단 자리에 둥근 화분용 크기를 그대로 얹으면 화단 밖으로 걸칩니다 |
| 앞뒤 순서 | 놓인 자리의 화면 높이. 화면에서 아래에 있는 것이 앞입니다 |
| 손이 닿는 곳 | 화분까지. 잎은 옆 칸 위까지 뻗으므로 잎으로 잡으면 엉뚱한 화분이 잡힙니다 |

## 확인하는 법

**작은 화면으로 판단하지 않습니다.** 접합부는 4배 이상 확대해야 어긋난
것이 보입니다. 화단에 두 그루가 겹쳐 한 덩어리로 보이던 것을 축소된
화면에서는 못 잡았습니다.

## 실측값

- 바닥 등각 **1.97 : 1** · 타일 170.2 × 79.8 · 격자 **4×4**

  4 는 안내 이미지에 그렇게 그려 달라고 한 수입니다. 예전에는 도구 기본값
  5 로 나누고 있었는데, 그러면 타일이 좁아 둥근 화분(무대에서 63.5px)이
  옆 칸과 겹칩니다. 4 면 칸 간격이 88px 이라 한 칸에 하나씩 들어갑니다.

- 조각과 무대의 축척 차이를 메우는 배율 **0.4097**

  표준 화분이 무대에서 **63.5px** 폭이 되는 값입니다. 온실 안에 이미
  그려진 작업대 화분·선반 화분에 견주어 눈으로 맞췄습니다. 처음에 0.62 로
  잡았더니 식물이 지붕을 뚫었습니다 — **타일이 크고 식물이 작은 것**이 이
  그림의 비율입니다.

  예전에는 이 값을 타일 폭의 비율(0.34)로 두었는데, 그러면 바닥을 몇
  칸으로 나누느냐에 따라 식물 크기까지 흔들립니다. 칸 수는 우리가 정하는
  것이고 화분 크기는 그림에 이미 정해져 있으므로, 그림 쪽에 붙여 두었습니다.
