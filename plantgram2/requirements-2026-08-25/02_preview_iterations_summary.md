## 1. 이터레이션별 요약

### ① Final Product Brief (2026-05-30) — "무엇을 만들 것인가"
- 방향: Plantgram1의 레거시 확장 메뉴(쇼핑/중고거래/클래스/상담/QR/결제/관리자)를 **전부 버리고**, "등록 → 돌봄 일정 → 사전 → 기록"의 반복 관리 루프에 집중
- **하단 4탭**: 내 식물 / 사전 / 기록 / 계정 (+보조 화면 5: 식물 상세, 등록·수정, 사전 상세, 식물별 커뮤니티, 기록 작성)
- 커뮤니티는 독립 탭이 아니라 **사전 상세에서 진입하는 식물 맥락형 기능**으로 격하
- 기록 유형 6종(물/영양제/분갈이/메모/상태/사진) + 필터 7종(전체 포함)
- 계정 = 최소 설정 5종 (프로필/닉네임/알림/공개설정/로그아웃), **Kakao 단일 로그인**
- AI 원칙 확립: 별도 AI 탭 없음, 기록 흐름 안에 삽입, **자동 저장 금지**, API 키는 Cloud Functions 경유, 이미지 질병 진단·범용 챗봇 MVP 제외
- AI 로드맵 AI-0~AI-4 (기록 경로 정리 → 상세 입력 → 기록 탭 확장 → Functions 파서 → 주간 요약)

### ② AI Planning Board (2026-06-01) — "무엇부터 할 것인가"
- 메뉴별 AI 우선도 배지: 기록 **"AI 1순위"** / 내 식물 "높음" / 사전 "중간" / 계정·커뮤니티 "낮음"
- **AI 우선순위 4단계 확정**:
  1. 자연어 기록 초안 (기록 탭 + 식물 상세) — 자동 저장 금지, 확인 후 기존 저장 흐름
  2. 주간 돌봄 요약 — 저장된 기록만 기반
  3. 내 식물 맞춤 사전 설명 — 단정적 진단 회피
  4. 커뮤니티 글쓰기 보조 — 기록 요약 수준으로 제한
- 배치 기준: 임팩트가 아니라 **"작은 성공 가능성이 높은 순서"**
- 예시 플로우: "몬스테라 물 줬고 새잎이 올라왔어" → 초안(식물: 몬스테라, 유형: 물주기+상태, 메모: 새잎이 올라옴) → 사용자 확인 후 저장

### ③ Source-Based Mockup (2026-06-01) — "실제로 뭐가 만들어졌나"
- plantgram2 Flutter 소스 24개 파일을 직접 읽고 정리한 **구현 검증 스냅샷**, 8개 화면
- 브리프에 없던 화면 2개 발견: **로그인(카카오)**, **식물 등록**(관리 기준 11항목)
- **소스에만 있던 기능들** (기획 문서가 구현을 과소 기술):
  - `Lv.N` 레벨 시스템 + 레벨 게이지 (게임화 요소)
  - "일괄로 물주기" 배치 액션
  - "관리 종료 / 관리 재시작" 라이프사이클
  - 영양제·분갈이는 주기 > 0일 때만 기록 항목 노출 (조건부 UI)
  - 상태 3단계: 좋음 / 보통 / 관심 필요
  - 날씨 카드 (OpenWeather, 조건별 그라디언트 + 순환 문구)
  - 식물 124종 도감 카운트
- 8개 화면 전부에 AI 후보 1:1 매핑 (가장 넓은 AI 후보 범위)

## 2. 세 이터레이션에서 흔들리지 않은 코어 (= 검증된 방향)

1. **하단 4탭 고정**: 내 식물 / 사전 / 기록 / 계정 — 한 번도 바뀌지 않음
2. **커뮤니티 = 식물 맥락형** (독립 탭 아님, 사전 상세에서 진입, "전체 게시판으로 확장하지 않는다" 3회 명문화)
3. **AI 1순위 = 기록 탭 자연어 초안** — 세 번 모두 동일 결론, 예시 문장까지 동일
4. **AI 자동 저장 절대 금지** — 3회 모두 명문화, 기존 저장 UI/Repository 재사용
5. 기록 유형 6종 + 필터 7종 (순서까지 동일)
6. 내 식물 내부 탭 3종: 내식물 / 일정 / 다이어리
7. 사전 뼈대: 검색 → 오늘의 식물 → 추천 섹션 → 목록 → 상세(관리정보+팁+유사식물+커뮤니티)
8. 계정 = 최소 설정 5종 + **Kakao 단일 로그인**
9. **레거시 절단 합의**: 쇼핑·중고거래·클래스·컨설팅·QR·결제·관리자 — 어디에도 재등장 없음
10. 이미지 질병 진단·상담 챗봇 = MVP 제외 (출시 후 검토)
11. 디자인 문법: 시스템 폰트, 그린 계열 강조, 카드 radius 8px, 폰 프레임 목업 규격

## 4. plantgram2 구현 현황 (소스 목업 기준으로 이미 존재하는 것)

- 카카오 로그인 → "식집사" 프로필 자동 생성
- 내 식물 홈: 날씨 카드 / 물주기 대상 카드("일괄로 물주기") / 등록 유도 카드, 내부 탭 3종
- 식물 등록 bottom sheet: 식물종 검색(최근 검색어) → 애칭 → 대표 이미지 → 관리 기준 11항목
- 식물 상세: 레벨 게이지, D-Day 카드(물/분갈이/영양제/추가 알림), 기록하기 액션시트 6종
- 기록 탭: 필터 7종 타임라인, 메모/상태 수정, 소프트 삭제, pull-to-refresh
- 일정 탭(다가오는 예정 정렬) / 다이어리 탭(필터 4종 + 이미지 프리뷰)
- 사전: 검색, 오늘의 식물, 추천 섹션 10종, 124종 목록, 상세(관리정보/팁/라벨/유사식물/키우는 사람들)
- 식물별 커뮤니티: 목록/작성/상세/댓글, 댓글 수 Functions 집계
- 계정: 닉네임 수정, 알림 스위치+시간(09:00, FCM), 내 식물 공개, 로그아웃
- 아키텍처: GetX + Repository 패턴, Firebase(Firestore/Functions), `myplant.is_public` 전파
