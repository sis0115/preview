# 메뉴 확정 및 기본 요건 리스트 — v0.2 (2026-08-26)

> 사용자 결정 반영: 하단 4탭 확정 + 주요 업데이트 3축(공동 관리 / 게임화·뱃지 / 꾸미기).
> 01~04 문서의 기능 요건을 새 메뉴 구조로 재배치하고, 신규 요건을 추가한 버전.

---

## 1. 확정 메뉴 (하단 4탭)

| # | 탭 | 성격 | 통합된 것 |
|---|---|---|---|
| 1 | **피드** | 자랑·소통 (토스 커뮤니티 유사) | 구 커뮤니티(식물별 게시판)를 피드 안으로 통합 |
| 2 | **내식물관리** | 관리 + 기록 | 구 "내 식물" 탭 + 구 "기록" 탭 통합 |
| 3 | **도감** | 식물 사전 | 구 "사전" 그대로 |
| 4 | **계정** | 프로필·꾸미기·설정 | 구 "계정" + 꾸미기·뱃지 진열장 신설 |

v0.1 대비 구조 변화:
- 기록 탭이 내식물관리로 흡수 → 빈 슬롯에 피드가 들어옴
- "커뮤니티는 식물 맥락형(사전에서만 진입)" 결정을 **부분 번복** — 단, 레거시의 인스타형 팔로우 피드가 아니라 **뱃지·성장 자랑 중심의 주제형 피드**로 성격을 다르게 정의

## 2. 주요 업데이트 3축 (v0.1에 없던 신규 방향)

### U-1. 공동 관리 (Shared Care)
계정별 "내 식물"은 디폴트이되, **다른 사람을 초대해 함께 관리**할 수 있다.
- 사용 시나리오: 가족·커플·룸메이트가 같은 식물을 함께 돌봄, 장기 부재 시 지인에게 돌봄 위임
- 핵심 요건:
  - 초대: 초대 링크(카카오톡 공유) → 수락 시 멤버 합류
  - 역할: 소유자(등록·수정·멤버관리·삭제) / 멤버(조회·기록·물주기)
  - 공동 기록: 모든 기록에 "누가" 표시 — "오늘 오전 민수가 물을 줬어요"
  - 중복 방지: 이미 오늘 물 준 식물은 다른 멤버에게 상태 반영 (일괄 물주기·D-Day 공유)
  - 알림: 멤버가 기록하면 다른 멤버에게 푸시(설정 가능)
  - 탈퇴/내보내기, 소유권 이전
- 데이터 영향: `myplants`가 단일 소유(uid)에서 **멤버십 모델**(ownerUid + memberUids[])로 확장. 모든 기록에 actorUid 필수

### U-2. 게임화 — 뱃지 + 레벨 + 피드 자랑 (토스 커뮤니티 유사)
식물 관리를 게임 형태로 제공하고, 성과를 뱃지로 발급해 피드에 자랑할 수 있게 한다.
- 레벨: 식물별 Lv.N + 경험치 게이지(plantgram2 기존 구현 계승·확장) — 기록·돌봄 활동으로 상승
- 뱃지 체계 초안 (카테고리별):
  - 시작: 첫 식물 등록 / 첫 물주기 / 첫 사진 기록
  - 꾸준함: 7일 연속 기록 / 30일 연속 / 물주기 지각 없이 한 달
  - 마일스톤: 함께한 지 100일·1년 / 식물 Lv.10 / 첫 개화 기록 / 식물 5그루·10그루
  - 함께: 첫 초대 / 함께 관리 30일 / 멤버와 번갈아 물주기 10회
  - 소통: 첫 게시글 / 좋아요 50 / 도움 답변 채택
- 자랑 흐름: 뱃지 획득 모달 → **"피드에 자랑하기" 원클릭** → 뱃지 자동 카드 생성 게시
- 원칙: 뱃지는 돌봄 행동을 강화하는 방향으로만 설계 (기록 조작 유인 최소화, 소급 발급 지원)

### U-3. 꾸미기 — 홈 카드 + 식물 아바타
"내 카드 꾸미기"처럼 홈을 꾸미고, 등록한 식물에 아바타를 부여하는 게임 요소.
- 홈(내식물관리) 카드 꾸미기: 카드 테마·배경·프레임 선택
- 식물 아바타: 식물별 캐릭터/아이콘 선택(사진 대신 또는 사진과 병행 표시), 레벨에 따라 성장하는 아바타 형태 검토
- 프로필 꾸미기: 대표 뱃지 지정, 뱃지 진열장, 프로필 테마
- 해금 방식: 미정 (D-9) — 전부 무료 vs 활동 포인트로 해금

## 3. 메뉴별 기본 요건 리스트

### 탭 1. 피드
**기본 (레거시·v0.1에서 계승)**
- [F-1] 통합 피드: 최신순 기본, 사진+텍스트 게시물
- [F-2] 식물별 게시판 통합: 식물종 채널(태그) 필터 — 도감 상세의 "OO 이야기"가 여기로 연결
- [F-3] 게시물 작성: 사진(최대 3) + 본문 + 식물종 태그 + 내 식물 태그
- [F-4] 좋아요 / 댓글(1단) / 댓글 수 집계 + 푸시
- [F-5] 신고·차단·숨김 (스토어 심사 필수 요건)
- [F-6] 내 식물 태그 → 해당 식물 공개 프로필로 연결
**신규 (U-2 연동)**
- [F-7] 뱃지 자랑 카드: 뱃지 획득 시 원클릭 게시(자동 생성 카드)
- [F-8] 성장 자랑 카드: 레벨업·D+100·개화 등 마일스톤 자동 카드
- [F-9] 주제형 구조: 팔로우 그래프 없이 주제(식물종·태그) 중심 (D-10에서 확정)
**AI**: 글쓰기 보조(기록 요약 초안) — 4순위 유지

### 탭 2. 내식물관리
**기본 (구 내식물+기록 통합)**
- [M-1] 홈 카드: 날씨 / 물주기 대상 N개 + **일괄 물주기** / 내 식물 요약
- [M-2] 식물 등록: 식물종 검색 → 애칭 → 사진 → 관리 기준 11항목
- [M-3] 식물 카드: 아바타/사진, 애칭, Lv.N, 물주기 D-Day, 원터치 물주기
- [M-4] 식물 상세: D-Day 카드(물/영양제/분갈이/추가 알림), 레벨 게이지, 요약
- [M-5] 기록 6종 액션시트: 물주기 / 영양제(주기>0) / 분갈이(주기>0) / 메모 / 사진 / 상태(3단계)
- [M-6] 기록 타임라인: 필터 7종, 메모·상태 수정, 소프트 삭제 (구 기록 탭 → 내부 탭/서브 화면으로)
- [M-7] 일정 뷰: 다가오는 물·영양제·분갈이 예정
- [M-8] 다이어리: 사진·메모·상태 필터 + 이미지 프리뷰
- [M-9] 관리 종료 / 재시작
- [M-10] 물주기 푸시(시각 선택), 물주기 직후 리뷰 유도
**신규 (U-1, U-2, U-3 연동)**
- [M-11] 멤버 초대·수락·탈퇴, 역할 관리 (U-1)
- [M-12] 기록에 행위자 표시 + 멤버 활동 알림 + 중복 물주기 방지 (U-1)
- [M-13] 경험치·레벨 상승 + 뱃지 트리거 (U-2)
- [M-14] 홈 카드 꾸미기 / 식물 아바타 (U-3)
**AI**: 자연어 기록 초안(1순위) / 주간 돌봄 요약(2순위) — 위치는 이 탭 내

### 탭 3. 도감
- [D-1] 검색 (식물명, 오타 보정은 AI 후순위)
- [D-2] 오늘의 식물
- [D-3] 추천 섹션 10종 (초보/공기정화/인테리어/반려동물 주의/아이 주의/물/햇빛/따뜻/최신/인기)
- [D-4] 식물 목록 (124종+ 레거시 DB 이관)
- [D-5] 상세: 기본 정보 / 관리 정보(물·햇빛·수분·온도) / 추천·주의 라벨 / 관리 팁
- [D-6] 비슷한 식물
- [D-7] 이 식물을 키우는 사람들 (공개 설정 유저)
- [D-8] "{식물명} 이야기" → **피드 탭의 해당 식물 채널로 이동** (v0.1과 달라진 연결)
- [D-9] 등록 진입: 도감 상세에서 "내 식물로 등록"
**AI**: 내 식물 맞춤 사전 설명(3순위)

### 탭 4. 계정
**기본**
- [A-1] 프로필 (아바타·닉네임·수정)
- [A-2] 알림 설정 (푸시 on/off + 시각)
- [A-3] 내 식물 공개 설정
- [A-4] 약관·개인정보 / 로그아웃 / 회원탈퇴
- [A-5] 로그인: Kakao (+Apple 등은 D-1 결정)
**신규 (U-2, U-3 연동)**
- [A-6] 뱃지 진열장: 전체 뱃지 컬렉션(획득/미획득), 대표 뱃지 지정
- [A-7] 프로필 꾸미기: 테마·프레임, 대표 식물 지정
- [A-8] 내 돌봄 통계: 누적 물주기, 연속 기록일, 함께한 날
- [A-9] 공동 관리 현황: 내가 참여 중인 식물, 받은 초대 관리

## 4. 횡단 시스템 요건

- [S-1] 게임화 엔진: 경험치 규칙 테이블, 뱃지 조건 판정(Cloud Functions), 획득 이력
- [S-2] 멤버십 모델: `myplants.ownerUid + memberUids[]`, 모든 기록에 `actorUid`, 초대 토큰
- [S-3] 아바타/꾸미기 에셋 관리: 에셋 카탈로그, 유저 보유/장착 상태

- [S-5] Firebase 단일 백엔드 + Firestore 단일 원본 (v0.1 유지)
- [S-6] AI: Cloud Functions 경유, 자동 저장 금지 (v0.1 유지)

## 5. 새로 생긴 결정 필요 항목 (D-9 ~ D-12)

| # | 질문 | 선택지 | 참고 |
|---|---|---|---|
| D-9 | 꾸미기 해금 방식 | ⓐ 전부 무료 ⓑ 활동 포인트로 해금 ⓒ 일부 유료(수익화) | ⓑ면 포인트 경제 설계 필요, ⓒ면 D-7(수익화) 재검토 |
| D-10 | 피드 구조 | ⓐ 팔로우 없이 주제 중심(토스식) ⓑ 팔로우 부활 | ⓐ 추천 — 레거시 팔로우 그래프 실패 경험, 토스 커뮤니티도 팔로우 없음 |
| D-11 | 공동 관리 단위 | ⓐ 식물 단위 초대 ⓑ "정원(스페이스)" 단위(공간을 공유하면 그 안의 식물 전체 공유) | ⓑ가 가족 시나리오에 자연스러움, ⓐ가 구현 단순 |
| D-12 | 유저 레벨(집사 레벨) | ⓐ 식물 레벨만 ⓑ 식물 레벨 + 집사 레벨 병행 | 뱃지가 유저 성취를 담당하면 ⓐ로 충분할 수 있음 |

**기존 D-1~D-8 상태**: D-4(레벨) = **유지 확정**. 나머지(D-1 로그인, D-2 게스트, D-3 기록 유형, D-5 날씨, D-6 컬러, D-7 수익화, D-8 개발 베이스)는 여전히 대기.
- 참고: D-8(개발 베이스)은 이번 방향 전환으로 **신규 시작 쪽으로 기울어짐** — 피드·게임화·공동 관리는 plantgram2 구조에 없던 축이라 이어받는 이점이 줄어듦. 단, plantgram2의 관리 코어 코드는 참조 자산으로 유효.
