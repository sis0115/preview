# 게임화 · 정원 · 가족 계정 · AI 설계안 — v0.3 (2026-08-26)

> 사용자 결정 반영: 꾸미기 전부 무료(D-9 확정), 계정 레벨 병행(D-12 확정), 부모-자식 계정 구조(D-11 방향 확정).
> 신규: 식물 아바타 자동 생성·커스텀, 정원 홈 뷰, 점수제, 레벨업 셀레브레이션, AI 식물·환경 분석 서비스(유료 허용).

---

## 1. 식물 아바타 시스템

### 1-1. 자동 생성
- **식물 등록 시 식물종 기반 기본 아바타 자동 생성**
- 구현: 도감 식물종(124종+)을 **형태 카테고리 12~15종**으로 매핑 (대엽형·직립형·선인장형·덩굴형·야자형·관목형·꽃형·다육형·양치형·수경형 등)
- 아바타 = 레이어 조합: `종 베이스 실루엣 × 성장 단계 × 화분 × 소품`

### 1-2. 커스텀 (전부 무료 — D-9 확정)
| 파츠 | 옵션 예시 |
|---|---|
| 화분 | 모양(원형/사각/항아리/걸이), 색상, 패턴(무지/줄무늬/도트/테라코타) |
| 식물 크기 | S / M / L (실제 크기 반영 or 취향) |
| 잎 형태 | 카테고리 내 변형 2~3종 (둥근잎/뾰족잎/갈라진잎), 색조(연두~진초록, 무늬종) |
| 소품 | 이름 팻말, 지지대, 스티커, 계절 소품 |

### 1-3. 성장 연동
- 레벨 구간마다 아바타 성장 단계 변화: **새싹 → 잎 전개 → 무성 → 만개/완성** (4~5단계)
- 상태 반영: 물주기 지남 → 잎이 처지는 모션 + 물방울 말풍선 / 관리 종료 → 화분만 남김("졸업" 처리)

### 1-4. 제작 방식 (기술 제안)
- **1안(권장): 에셋 기반 레이어드 2D** — SVG/스프라이트 파츠 조합. 일관된 아트 스타일, 오프라인 렌더, 비용 0
- 2안: AI 이미지 생성(등록 시 1회 생성) — 개성은 높으나 스타일 일관성·비용·재생성 문제 → **후순위 이벤트 기능으로** (예: "내 식물 초상화 만들기")

## 2. 정원 홈 (Garden View)

- 내식물관리 홈에 **정원 뷰 ↔ 리스트 뷰 토글**
  - 정원 뷰 = 게임성·정서 / 리스트 뷰 = 관리 효율 (D-Day 정렬·일괄 물주기)
- 배경 테마(무료): 창가 / 베란다 난간 / 원목 선반 / 온실 — 아바타들이 자연스럽게 배치됨
- 배치 편집: 드래그로 위치·순서 조정, 슬롯 확장(식물 수에 따라 선반 층 추가)
- **정원에서 바로 관리**: 물이 필요한 식물은 시든 모션+말풍선 → 탭하면 물주기 실행 (다마고치식 인터랙션)
- 시간·날씨 연출: 실제 시간대(아침/낮/저녁)·날씨 API와 연동된 배경 톤 변화
- 정원 자체가 공유 단위: 정원 스크린샷 = 피드 자랑 카드 (레거시 "예쁘게 캡쳐해서 공유하기" 부활)

## 3. 점수 · 레벨 시스템

### 3-1. 그로우 포인트(GP) 획득 규칙 (초안)
| 행동 | GP | 비고 |
|---|---|---|
| 물주기 (제때: D-Day ±1일) | +10 | 지각 물주기는 +3 |
| 영양제/분갈이 (제때) | +15 | 저빈도 행동 가중 |
| 일기(메모/사진) 작성 | +5 | 1식물 1일 1회 인정 |
| 상태 기록 | +3 | |
| 연속 기록 보너스 | 7일 +20 / 30일 +100 | 스트릭 시스템 |
| AI 분석 실행 후 권장 조치 수행 | +10 | AI ↔ 게임화 연결 |
- **어뷰징 방지**: 식물당 일일 GP 상한, 물주기는 주기 대비 과도 시 미인정(과습 방지 겸용)

### 3-2. 식물 레벨
- 식물별 GP 누적 → 레벨 커브(초반 빠르게, 후반 완만) — plantgram2 Lv.N 계승·확장
- **레벨업 셀레브레이션**: 토스식 전면 이벤트 — 폭죽/컨페티 애니메이션(Lottie) + 아바타 성장 연출 + "피드에 자랑하기" 버튼
- 레벨업 보상: 새 커스텀 파츠 개방(무료지만 레벨로 개방 = 수집 동기), 뱃지 트리거

### 3-3. 계정(집사) 레벨 — D-12 확정: 병행
- 정원의 모든 식물 GP가 **정원(계정) 레벨**로 합산
- 계정 레벨업도 동일한 셀레브레이션 + 계정 전용 뱃지·칭호 (예: Lv.10 "새싹 집사" → "정원사" → "식물 마스터")
- 계정 레벨 보상: 정원 배경 테마 개방, 프로필 프레임 개방

## 4. 가족 계정 (부모-자식) — D-11 방향 확정

- **절대 원칙: 한 계정이 부모(소유자)** — 식물·정원의 소유권은 항상 부모 계정에 귀속
- 자식 계정: 초대 링크(카카오 공유)로 합류 → 부모 정원의 식물을 **함께 편집·관리·기록**
- **점수 공유**: 자식의 활동 GP도 부모 정원 레벨에 합산 — "점수를 같이 먹는" 공동 레벨업. 셀레브레이션은 전 멤버에게 발생
- 개인 기여: 멤버별 기여도 통계(누가 몇 % 돌봤는지) + 자식 계정의 개인 뱃지는 별도 적립
- 공유 단위: **정원 단위** (부모 정원에 합류하면 그 안의 식물 전체 공동 관리) — 식물 단위보다 가족 시나리오에 자연스러움
- 세부 규칙: 자식은 여러 정원에 참여 가능(내 정원 + 부모님 정원), 내보내기/탈퇴, 소유권 이전(1회성), 기록의 행위자(actor) 영구 표기
- 데이터 모델: `gardens/{id}: ownerUid, memberUids[], gp, level` / `myplants.gardenId` / `plant_actions.actorUid`

## 5. AI 서비스 — 유료 허용 (v0.1 "이미지 진단 제외" 원칙 공식 폐기)

### AI-A. 식물 상태 리포트 (누적 이미지 일괄 분석)
- 입력: 해당 식물에 지금까지 올린 사진 전체(시계열) + 기록 이력 + 도감 기준
- 출력: 성장 변화 요약(잎 수·크기·색 변화), 현재 상태 판단, 주의 신호(잎끝 마름·황변·웃자람), 권장 조치
- 톤 원칙 유지: **단정 진단 회피** — "~로 보여요, ~을 권장해요" + 심각 소견 시 전문 검색/상담 안내

### AI-B. 환경 분석 (신규 킬러 기능 후보)
- 입력: **식물이 놓인 자리를 촬영한 사진** (+ 창 방향 질문 1~2개)
- 분석: 채광(직사/간접/부족, 창과의 거리), 통풍(창·문 배치), 화분 재질·배수 추정, 주변 환경(에어컨 바람, 라디에이터 등)
- 출력: 이 자리의 환경 점수 + **이 식물 기준** 과습·냉해·광부족 위험 안내 + 배치 개선 제안
- **관리 주기 자동 보정 제안**: "채광이 약한 자리라 물주기를 7일 → 9일로 늘리는 걸 추천해요" → 원탭 적용 (AI가 게임 루프에 실질 기여)

### 과금 설계 (신규 결정 D-13)
- 제안: **무료 크레딧 월 N회 + 구독(플랜트그램 플러스)** — 회당 결제보다 심리 장벽 낮고 반복 사용 유도
- 자연어 기록·주간 요약(경량 AI)은 무료 유지, 이미지 분석(고비용 vision)만 크레딧 차감
- 구현 원칙 유지: 사진 → Cloud Functions → Vision LLM, 키 서버측, 사용자별 요청 제한

### AI 우선순위 재편 (v0.3)
| 순위 | 기능 | 비고 |
|---|---|---|
| 1 | 자연어 기록 초안 | 무료, 기존 1순위 유지 |
| 2 | **AI-B 환경 분석** | 유료 후보, 차별화 킬러 기능으로 승격 |
| 3 | AI-A 상태 리포트 | 유료 후보 |
| 4 | 주간 돌봄 요약 | 무료 |
| 5 | 사전 맞춤 설명 / 글쓰기 보조 | 후순위 |

## 6. 추가 아이디어 (제안 — 채택 여부 자유)

1. **성장 타임랩스**: 올린 사진을 시간순으로 이어 GIF/짧은 영상 자동 생성 → 피드 자랑 카드. AI-A와 입력 데이터 공유
2. **홈스크린 위젯**: 정원 미니뷰 + 오늘 물 줄 식물 위젯(iOS/Android) — 리텐션 핵심 장치, 토스류 앱의 검증된 패턴
3. **계절 한정 꾸미기**: 봄 벚꽃·여름 비·겨울 눈 소품 (무료지만 기간 한정 → 재방문 유인, "무료 확정"과 충돌 없음)
4. **관리 종료 = "졸업" 연출**: 죽음을 실패가 아니라 함께한 기록으로 마무리(졸업장 카드 + 다이어리 아카이브) — 게임 톤 유지 + 이탈 방지
5. **정원 방문**: 피드에서 상대 프로필 → 상대의 공개 정원 뷰 구경 (좋아요 남기기) — 꾸미기와 피드를 잇는 고리
6. **용어 세계관**: 부모/자식 대신 **"정원 오너 / 가드너"** 같은 서비스 용어 제안 (UI 노출용)
7. **물주기 알림의 게임화**: 푸시 문구를 아바타 말투로 — "몬스테라가 목이 말라요 💧" (레거시 말풍선 감성 계승)
