## 1. 제품 정의

**"내 식물을 등록하면 아바타가 생기고, 함께 돌보며 정원을 키우는 게임형 반려식물 관리 앱"**

핵심 루프: 등록(아바타 생성) → 오늘 할 일(푸시/정원 뷰) → 기록(원터치·자연어) → GP 획득·레벨업(셀레브레이션) → 피드 자랑 → 반복
확장 루프: 가족 초대 → 공동 돌봄·공동 레벨업 / AI 분석 → 관리 주기 보정 → 더 나은 돌봄

하지 않는 것: 팔로우 그래프 / 커머스(중고거래·쇼핑·클래스·상담결제) / QR 하드웨어 / 광고 / 앱 내 어드민 / AI 자동 저장

## 2. 정보 구조 — 하단 4탭

### 탭 1. 피드 (주제 중심, 토스식)
- 통합 피드(최신순) + 식물종 채널(태그) — 팔로우 없음
- 게시물: 사진(≤3)+본문+식물종 태그+내 식물 태그 / 좋아요 / 1단 댓글(집계·푸시) / 신고·차단
- 자동 카드: 뱃지 획득 자랑, 레벨업·마일스톤(D+100, 개화), 정원 스크린샷
- 도감 상세 "{식물명} 이야기" → 해당 채널로 진입

### 탭 2. 내식물관리  *(v3 목업으로 구조 확정, 2026-08-26)*
- **홈 = 정원 뷰**: 아이소메트릭 온실(바닥 25칸+벤치 10칸+마당 10칸)이 홈 화면의 주인공.
  가든 레벨·GP 게이지 카드, 물이 필요한 식물 수, 식물 위 💧 D-Day 말풍선(탭 → 물주기 +GP),
  돌보기/꾸미기 모드 스위치. 배치 규칙: 소형만 벤치, 대형은 두 칸(위) 점유, 마당은 제한 없음
- **내 식물 = 보드 뷰 ↔ 리스트 뷰 토글** (호불호 대응)
  - 보드 뷰(기본): 3열 정사각 에디토리얼 그리드(핀터레스트 문법) — 칸마다 다른 타이포 구성,
    상세에서 꾸민 테마·스티커가 칸 배경에 그대로 반영. 배지·사진기록·주간 물주기 리포트 칸 포함
  - 리스트 뷰: 날씨 카드, 물주기 대상 N개 + 일괄 물주기, D-Day 정렬 행
- 식물 등록: 식물종 검색 → 애칭·사진 → 관리 기준 11항목 → **기본 아바타 자동 생성**
- **식물 상세 = 꾸민 카드로 진입** *(상세 테마 시스템)*
  - 진입 시 내가 꾸민 컬렉터블 카드(펀치홀·PLANTGRAM 바코드·유리광 창·와시테이프·스티커·태그 칩)가
    테마 배경 무대 위에 뜨고, 하단 시트를 위로 올리면 본 내용(요약·할 일·기록·AI 도구·CTA)
  - 🎨 꾸미기 = 같은 화면의 편집 상태: 테마 6종 / 패턴 4종 / 사진(일러스트↔내 사진, ✂️누끼 토글) /
    스티커 여러 장(최대 6, 퍼피 스타일) / 글자(서체 4종 + 글자색 5종) — 전부 무료, 카드 실시간 반영
  - 별도의 카드 관리 화면은 없다 — 화면이 곧 카드
- 기록: 6종 액션시트(자연어 입력이 첫 번째), 타임라인(필터 7종), 메모·상태 수정, 소프트 삭제 / 일정 뷰 / 다이어리
- 관리 종료 = "졸업" 연출(졸업장 카드+아카이브), 재시작 가능
- AI: 자연어 기록 초안(확인 후 저장), 주간 요약 — 무료 / 상세 도구 행에 AI-A(식물 검사)·AI-B(환경 분석) 진입

### 탭 3. 도감
- 검색 / 오늘의 식물 / 추천 섹션 10종 / 목록(레거시 124종+ 이관)
- 상세: 관리 정보·팁·라벨 / 비슷한 식물 / 키우는 사람들(공개 유저) / 채널 진입 / "내 식물로 등록"
- AI: 내 식물 맞춤 설명 (후순위)

### 탭 4. 계정
- 프로필·닉네임 / 알림(push+시각) / 내 식물 공개 / 약관 / 로그아웃·탈퇴
- 뱃지 진열장(대표 뱃지) / 프로필 꾸미기(테마·프레임) / 돌봄 통계
- 정원 관리: 내 정원 멤버, 참여 중인 정원, 받은 초대 / AI 구독·크레딧 관리

## 3. 게임 시스템

- **아바타**: 종 카테고리(12~15종) 베이스 × 성장 단계(4~5) × 화분 × 소품, 레이어드 2D 에셋(SVG). 상태 연동(시듦·졸업). 전부 무료, 일부 레벨 개방
- **GP 규칙**: 제때 물주기 +10(지각 +3) / 영양제·분갈이 +15 / 일기 +5 / 상태 +3 / 스트릭 보너스(7일 +20, 30일 +100) / AI 권장 조치 수행 +10. 일일 상한, 과도 물주기 미인정
- **식물 레벨**: GP 누적 커브, 레벨업 = 폭죽 셀레브레이션 + 아바타 성장 + 파츠 개방 + 자랑 버튼
- **정원(계정) 레벨**: 전 식물 GP 합산, 칭호(새싹 집사→정원사→식물 마스터), 배경 테마·프레임 개방
- **뱃지**: 시작/꾸준함/마일스톤/함께/소통 5카테고리, 획득 모달 → 피드 자랑 원클릭, 소급 발급 지원

## 4. 가족 계정 (정원 공유)

- 한 계정 = 절대 부모(소유자), 자식은 초대 링크(카카오)로 합류 → 공동 편집·기록
- 자식 GP도 부모 정원에 합산 → 공동 레벨업, 셀레브레이션 전 멤버 발생
- 멤버별 기여도 통계, 개인 뱃지 별도, 기록 행위자 영구 표기, 소유권 이전(1회성), 탈퇴/내보내기
- 자식은 자기 정원 + 타 정원 복수 참여 가능

## 5. AI 서비스

| 기능 | 과금 | 설명 |
|---|---|---|
| 자연어 기록 초안 | 무료 | 확인 후 저장, 자동 저장 금지 |
| 주간 돌봄 요약 | 무료 | 저장된 기록만 기반 |
| AI-A 식물 상태 리포트 | 크레딧 | 누적 사진 시계열 분석 + 기록·도감 대조 → 상태·주의 신호·권장 조치 |
| AI-B 환경 분석 | 크레딧 | 자리 사진 → 채광·통풍·배수 추정 → 과습·광부족 위험 + 배치 개선 + 주기 원탭 보정 |
- 과금: **무료 크레딧 월 N회 + 구독(플랜트그램 플러스)** — N과 가격은 비용 실측 후 결정
- 원칙: 단정 진단 회피 톤, 키는 Cloud Functions 경유, 사용자별 요청 제한, 민감 원문 장기 보관 금지

## 6. 기술 아키텍처 (신규 시작)

- Flutter 최신 stable (상태관리는 착수 시 Riverpod vs GetX 비교 선정, plantgram2 Repository 패턴 참조)
- Firebase 단일: Auth(Kakao·Google·Apple — Kakao는 커스텀 토큰 Functions) / Firestore(단일 원본+오프라인 캐시) / Storage / FCM / Functions(AI 프록시, 뱃지 판정, 댓글 집계, 푸시)
- 주요 컬렉션: `users` / `gardens`(ownerUid, memberUids[], gp, level) / `myplants`(gardenId, 관리기준, 아바타 구성, is_public) / `plant_actions`(actorUid, 6종, soft delete) / `plant_species`·`plant_tips`(레거시 이관) / `feed_posts`+`comments`(채널 태그) / `badges`·`user_badges` / `ai_jobs`(크레딧 차감 이력)
- 결제: 인앱 구독(StoreKit2/Play Billing) — AI 구독 단일 상품으로 시작
