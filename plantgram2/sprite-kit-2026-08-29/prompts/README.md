# 붙여넣는 프롬프트

각 `.txt` 는 **그 자체로 완결**입니다. 공통 규격·색값·크기 기준이 이미 안에
들어 있으므로 합칠 것이 없습니다. 파일을 열어 통째로 복사해 붙여넣으세요.

| 파일 | 시트 | 같이 첨부할 것 |
|---|---|---|
| `p1_plants.txt` | 01 식물 12종 (화분 없음) | `../tone-card.png` |
| `p2_stages.txt` | 02 성장 4단계 (한 종씩) | 톤 카드 + 01 시트 |
| `p3_pots_color.txt` | 03 화분·색 세트 | 톤 카드 + 01 시트 |
| `p4_pots_gray.txt` | 04 화분·무채색 세트 | 03 시트 |
| `p5_tiles.txt` | 05 지형 타일 | 톤 카드 + 01 시트 |
| `p6_greenhouse.txt` | 06 온실 부품 | 톤 카드 + 05 시트 |
| `p7_props.txt` | 07 소품 | 톤 카드 + 03 시트 |

`common.txt` 는 위 7개에 이미 포함된 공통 블록입니다 — 새 시트를 직접 쓸 때만
쓰세요.

**01번부터 순서대로** 받아야 톤이 이어집니다. 받은 PNG는 배경이 투명해야
낱개로 잘립니다. 자르기 전에 `python3 tools/check.py <시트> [--gray]` 로
투명도·덩어리 수·무채색·팔레트를 검사하세요.

## 성장 단계

01번 시트를 받은 뒤에는 아래 4장으로 12종 × 4단계 = 48개를 모두 받습니다.
한 장이 3종 × 4단계(4열 × 3행)이고, **네 장 모두 01번 시트를 첨부**해야
톤이 이어집니다.

| 파일 | 종 |
|---|---|
| `s1_stages_a.txt` | 몬스테라 · 여인초 · 대나무 |
| `s2_stages_b.txt` | 아레카야자 · 유칼립투스 · 디펜바키아 |
| `s3_stages_c.txt` | 금전수 · 피들리프 · 산세베리아 |
| `s4_stages_d.txt` | 스킨답서스 · 보스턴고사리 · 고무나무 |

`p2_stages.txt` 는 한 종씩 받던 옛 방식입니다 — 새 종을 하나만 추가할 때 쓰세요.

### 받은 시트에서 확인된 것

첫 시트는 배경이 완전 투명이 아니라 **옅은 초록 안개(alpha 1~30)가 15%**
깔려 있었습니다. alpha 40 임계값으로 지우면 12/12 깨끗하게 잘립니다.
위 4개 프롬프트에는 그 현상을 막는 문구가 들어 있습니다.

또 ChatGPT가 평면 벡터 대신 **회화체로 그렸습니다.** 팔레트는 6개 기준색이
모두 통과했으므로, 지시를 충돌시키지 않도록 단계 프롬프트에서는 평면 벡터
문구를 빼고 "첨부한 시트와 똑같이"로 바꿨습니다.
