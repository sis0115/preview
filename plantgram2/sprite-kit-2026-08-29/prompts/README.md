# 붙여넣는 프롬프트

각 `.txt` 는 **그 자체로 완결**입니다. 파일을 열어 통째로 복사해 붙여넣으세요.

## 톤 기준

`sheets/potted_a.png` (화분 식물 47종) 가 **톤 기준**입니다.
**모든 프롬프트에 이 시트를 첨부**해야 합니다. 말로 적은 색값보다
그림 한 장이 정확합니다.

측정값 — 톤 카드 6개 기준색까지의 거리:

| 시트 | 거리 범위 | 판정 |
|---|---|---|
| `plants_01.png` (회화체) | 4.4 ~ 30.6 | 화분 계열이 크게 벗어남 |
| **`potted_a.png`** | **1.0 ~ 6.1** | 기준으로 채택 |

## 순서

| 파일 | 시트 | 같이 첨부 |
|---|---|---|
| `s1_stages_a.txt` | 몬스테라 · 여인초 · 대나무 | `sheets/potted_a.png` |
| `s2_stages_b.txt` | 아레카야자 · 유칼립투스 · 디펜바키아 | 〃 |
| `s3_stages_c.txt` | 피들리프 · 산세베리아 · 금전수 | 〃 |
| `s4_stages_d.txt` | 장미 · 라벤더 · 토마토 | 〃 |
| `p3_pots_empty.txt` | 빈 화분 10종 | 〃 |
| `p5_tiles.txt` | 지형 타일 8종 | 〃 |
| `p6_greenhouse.txt` | 온실 부품 10종 | 〃 |
| `p7_props.txt` | 소품 12종 | 〃 |

단계 시트는 한 장이 3종 × 4단계(4열 × 3행)입니다. 네 장이면 12종 × 4단계
= 48개가 나옵니다.

## 확정된 사항

**화분은 식물에 붙은 채로 갑니다.** 채택한 시트가 그렇게 그려져 있고,
나눠 받으면 흙 경계선이 안 맞아 겹칠 때 틈이 보입니다.
따라서 `potColor` 곱하기 커스텀은 쓰지 않습니다 — 대신 시트에 이미
화분이 7종(테라코타 / 흰 도자기 / 민트 / 차콜 / 회색 큐브 / 나무 / 유리)
들어 있어 그것으로 다양성을 냅니다.

## 생성기가 반복하는 두 가지 결함

프롬프트에 이미 막는 문구가 들어 있지만, 받은 뒤 `check.py` 로 확인하세요.

1. **옅은 안개** — 배경이 완전 투명이 아니라 alpha 1~39 픽셀이 깔립니다
   (`plants_01` 15%, `potted_a` 12%, `potted_b` 3%).
   alpha 40 임계값으로 지우면 됩니다.
2. **검은 접지 그림자** — `potted_b` 는 그림자가 검고 진해서 타일 위에
   올리면 때처럼 보입니다. `potted_a` 처럼 옅은 회색이어야 합니다.
