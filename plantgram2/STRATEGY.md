# 전략 — 왜 못 만들었고, 무엇을 바꾸는가

## 못 만든 이유

**우리는 그림을 받고 나서 그 기하를 알아내려 했습니다.** 알아내기는 매번
실패했고, 시트가 바뀌면 또 실패합니다.

지금까지 코드가 그림에서 알아내려 한 것들:

| 알아내려 한 것 | 방법 | 결과 |
|---|---|---|
| 바닥 격자 | 바닥 네 꼭짓점에서 되짚음 | 평행사변형 오차 31.9px, 칠해진 타일과 어긋남 |
| 화분의 흙 | 색(hue)으로 찾음 | 맞았지만 흙 색이 다른 화분이 오면 깨짐 |
| 화분이 닿는 자리 | 실루엣에서 다리 찾기 | 둥근 화분과 다리 달린 화단에 각각 다른 규칙이 필요 |
| 식물 밑동 | 맨 아랫줄 폭의 한가운데 | 세 번째 시도에 겨우 맞음 |
| 조각 축척 | 눈으로 맞춘 상수 | 0.62 → 0.34 → 0.4097, 두 번 틀림 |
| 화단 길이 | 코드로 2.11배 확대 | 화분들과 축척이 어긋나 잘려 보임 |

**잰 값도 결국은 추측입니다.** 그림이 우리 뜻대로 그려졌다는 보장이 없으면,
아무리 정교하게 재도 다음 시트에서 또 틀립니다.

## 바꾸는 것 — 방향을 뒤집는다

> 우리가 기하를 정하고, 그림은 그 안에 그려져 온다.
> 돌아온 그림은 **재지 않는다. 맞는지 확인만 한다.**

칸마다 이것을 먼저 그려 보냅니다.

- **밑면** — 바닥에 닿을 타일 (1칸 / 2칸 / 2×2)
- **좌우 한계** — 잎이 넘지 말아야 할 선
- **흙 윗면 / 선반 판** — 식물이 놓일 높이
- **십자** — 식물 밑동이 놓일 점

**키는 정하지 않습니다.** 밑면만 맞으면 놓는 데 문제가 없고, 키까지 묶으면
그림 쪽 자율성만 깎입니다. 앞뒤 순서도 놓인 자리의 화면 높이로 정하므로
키를 알 필요가 없습니다 — "이건 최대 몇 칸짜리"라고 코드가 넘겨짚어 자리를
못 잡는 일이 없습니다.

그러면 앱이 쓰는 좌표는 전부 **우리가 보낸 spec.json** 에 이미 있습니다.
색으로 흙을 찾지도, 실루엣으로 다리를 찾지도 않습니다.

조합도 한 줄이 됩니다 — **식물의 십자를 화분의 십자에 놓는다.** 둘 다 우리가
정한 점이므로 어긋날 데가 없습니다.

## 파이프라인

```
make_spec.py    안내 이미지 + spec.json 을 만든다        ← 기하는 여기서 정해진다
      ↓  (사람이 생성기에 넣는다)
verify_spec.py  돌아온 그림이 안내선을 지켰는지 검사한다  ← 어기면 거절, 흡수 금지
      ↓
slice_spec.py   칸을 오려 내고, 좌표는 spec.json 에서 가져온다
```

**어기면 거절합니다.** 지금까지는 어긋난 그림을 받아 코드로 흡수했고, 그게
뒤틀림과 잘림의 뿌리였습니다.

## 규칙

**코드가 고쳐도 되는 것** — 놓는 위치, 앞뒤 순서, 손이 닿는 범위, 격자 좌표,
접지 그림자, 저장·되돌리기.

**코드가 고치면 안 되는 것** — 조각 하나만 확대·축소, 색조 변경, 형태 변경.
이런 게 필요하면 **시트를 다시 받습니다.** (화단 2.11배가 이 규칙 위반이었습니다)

**한 번에 하나만 바꾸고**, 같은 화면 같은 배율의 전/후를 냅니다.

**"됐습니다"라고 말하지 않습니다.** 검수 이미지와 수치표를 내고 판정을 받습니다.

## 시트 계획

| | 시트 | 검증하는 것 |
|---|---|---|
| 1 | **규격 시험지** (지금) | 생성기가 밑면과 흙 높이를 지키는가 |
| 2 | 배경 | 우리가 그린 바닥 격자 위에 온실을 그려 오는가 |
| 3 | 가구·소품 | 선반·작업대의 놓는 자리가 지켜지는가 |
| 4 | 종·성장 단계 | 같은 규격으로 종을 늘릴 수 있는가 |

1번이 실패하면 나머지는 의미가 없으므로 여기부터 시험합니다.

## 배경은 왜 뒤집어야 하나

바닥만 우리가 그리고 벽·소품은 그림 것을 쓰면 두 그림의 각이 어긋납니다
(이번에 확인). 반대로 **우리가 그린 바닥 격자 위에 온실 전체를 그려 달라고
하면**, 벽과 소품이 우리 바닥에 맞춰 그려집니다. 시트 2에서 이걸 시험합니다.

## 슬롯 등급

식물 하나가 들어가는 자리를 **슬롯**이라 하고, 크기 등급을 붙입니다.

| 슬롯 | 들어가는 식물 | 가진 것 |
|---|---|---|
| 1칸 | 밑면 1칸 | 둥근 화분 1개 · 긴 화단 2개 · 선반 각 층 2개씩 |
| 2×2 | 밑면 4칸 | 큰 화분 1개 |

**두 칸짜리 화단은 두 칸을 덮는 식물 하나가 아니라, 한 칸짜리 식물 두 그루를
심는 자리입니다.** 밑면 2칸짜리 식물은 만들지 않습니다.

식물과 슬롯의 등급이 맞아야 놓입니다. 등급이 다르면 코드가 크기를 조절하는
게 아니라 **놓을 수 없다고 알려 줍니다.**
